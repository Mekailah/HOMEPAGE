# RIDEGO RENTALS

RIDEGO RENTALS is a web-based motorcycle rental system developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features

- User registration and login
- Customer and admin roles
- Motorcycle browsing and booking
- Motorcycle inventory tracking
- GCash and BPI payment options
- QR payment instructions
- Admin booking and inventory management

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- phpMyAdmin

## Setup

1. Place the RIDEGO folder inside `xampp/htdocs`.
2. Start Apache and MySQL in XAMPP.
3. Import `database/database.sql` using phpMyAdmin.
4. Open `http://localhost/RIDEGO/` in your browser.

## Security

The system uses prepared statements, password hashing, session authentication, server-side validation, and role-based admin access.
